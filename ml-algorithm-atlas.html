The ML Algorithm Atlas

An interactive framework of twelve core machine learning algorithms, from classical tabular models to the transformers and diffusion models behind generative AI. You can see how each one learns, where it is used, and how it relates to the others, and you can run every algorithm live in your browser.

1 · How the algorithms relate

Each node is an algorithm, colored by how it learns. The lines connect algorithms that share ideas, architecture, or purpose. Hover over a node to trace its relatives, and click it to run its live demo.

Supervised: learns from labeled examples Unsupervised: finds structure without labels Self-supervised: creates its own targets from raw data
Tree → Forest → Boosting: one tree, then many voting trees, then trees that fix each other's errorsBERT ↔ GPT: the same transformer, reading in two directions vs. oneGAN ↔ Diffusion: two routes to generating images

2 · The live lab: watch each algorithm learn

Every demo runs the actual idea behind the algorithm in real time. You can drag the sliders, click the chart to add data, and step through training to see why each algorithm behaves the way it does.

4 · Head-to-head comparison

Pick any two algorithms to compare their trade-offs. The trade-off that matters most in practice is usually interpretability vs. accuracy ceiling.

Ratings run from 1 to 5. They are relative, illustrative judgments based on common practice, not benchmark scores.

5 · Which algorithm should I use?

Answer up to four questions to get a ranked shortlist, with the reasoning for each pick.

6 · Algorithm profiles

These are the reference cards. Each one gives the algorithm's type, application domains, a plain-language explanation of how it works, and real-world use cases from healthcare, finance, and beyond.
