The big picture

How data flows through a network

Data enters at the input layer, is transformed by each hidden layer, and leaves the output layer as a prediction. The loss function scores that prediction, and the error flows backwards so the optimizer can adjust every weight. That loop is one training step.

One training step
  1. Input features enter the network
  2. Weighted sum: inputs × weights + bias
  3. Activation function adds non-linearity
  4. Repeat for every hidden layer
  5. Output layer produces the prediction
  6. Loss function compares it with the true answer
  7. Backpropagation + optimizer update every weight
Component 01 · Layers

Layers organize the work into stages

A layer is a group of neurons that process data at the same stage. Each layer takes the previous layer's output, transforms it, and passes a new representation forward. The number of layers is the network's depth; the neurons per layer are its width.

Input layer

Receives the raw data, with one neuron per feature (for example transaction amount, time of day, merchant category). It does no computation. It hands the values to the first hidden layer.

Hidden layers

This is where learning happens. Every neuron combines all the outputs of the layer before it. Early layers pick up simple patterns, and later layers combine them into more abstract ones.

Output layer

Turns the final representation into the answer. Its size and activation are set by the task: one sigmoid neuron for yes/no, one softmax neuron per class, or a linear neuron for a number.

Each layer only has to learn a small step on top of the one before it, which is why depth helps with complex data such as images, text and audio.

Design the output layer for a task

Other layer types: dense (fully connected, used here), convolutional (images), recurrent and attention (sequences and language), and dropout or normalization layers that make training more stable.

Component 02 · Neurons

A neuron: weigh, add, then decide

A neuron is the basic computing unit. It multiplies each input by a weight, adds them together with a bias to get z, then passes z through an activation function to produce its output a. That output becomes an input to every neuron in the next layer.

Component 03 · Weights & biases

Weights are what the network learns

Weights set how strongly each input influences a neuron, and their sign says whether it pushes the output up or down. The bias shifts the neuron's threshold. Before training they are random; training means finding the values that make the predictions right.

  • Changing b slides the boundary without rotating it.
  • A real network has thousands to billions of these numbers, but each one does this same job.
Component 04 · Activation functions

Activation functions bend the line

An activation function decides how strongly a neuron "fires" for a given z. It adds non-linearity. Without it, any stack of layers collapses into a single linear equation and could only ever draw straight boundaries.
Hover over the chart to read values.

The derivative matters because training follows it. Where it is near zero (the flat ends of sigmoid and tanh), gradients vanish and learning slows. That is a big reason ReLU became the default for hidden layers.

Component 05 · Loss functions

The loss function keeps score

A loss function turns "how wrong was the prediction?" into one number. Training is the search for weights that make this number as small as possible, so the choice of loss defines what the network is actually trying to do.

A fraud model scores one transaction
Truth:

regression

Mean squared error

Average of (prediction − truth)². Squaring punishes big misses heavily. Used for predicting numbers such as price or length of stay.

regression

Mean absolute error

Average of |prediction − truth|. Less sensitive to outliers than MSE, so one extreme value doesn't dominate training.

binary classification

Binary cross-entropy

−[y·log(p) + (1−y)·log(1−p)]. It grows without limit as a wrong prediction becomes more confident. Paired with a sigmoid output.

multi-class

Categorical cross-entropy

The same idea across K classes: −log of the probability given to the correct class. Paired with a softmax output.

Component 06 · Optimization algorithms

Optimizers walk downhill on the loss

An optimization algorithm decides how to change the weights to reduce the loss. Backpropagation computes the gradient (which direction is uphill for every weight), and the optimizer takes a step the other way. The learning rate sets the size of that step.

Contours show a loss surface over two weights, with the minimum at ★. Click anywhere to start all four optimizers from that point.

  • SGD steps straight down the gradient. Simple, but it zig-zags across narrow valleys.
  • Momentum keeps a running velocity, so it speeds up along consistent directions.
  • RMSProp scales each weight's step by its recent gradient size.
  • Adam combines momentum with per-weight scaling. It is the most common default.

Try a learning rate near 0.9: SGD starts bouncing between the valley walls. At 0.02 every optimizer crawls.

Summary

Why visualizing neural networks matters

Seeing it changes how you understand it
  • It makes the invisible visible. Weights and activations are just numbers. Shown as line thickness, color and decision boundaries, they reveal what the model has actually learned.
  • It speeds up debugging. A flat loss curve, a loss that explodes, or a boundary that wraps around single noisy points each points to a specific fix: learning rate, capacity, features or more data.
  • It builds trust. In regulated fields like finance and healthcare, being able to show stakeholders how a model reaches its decisions matters as much as accuracy.
Key insights from this exercise
  1. Non-linear activations give depth its power. With a linear activation, eight layers behave like one.
  2. Good features can replace model size. Adding X₁² and X₂² let a network with no hidden layers solve the circle.
  3. The loss defines the goal. Cross-entropy punishes confident mistakes far more than squared error.
  4. The learning rate decides whether training converges. Too high bounces, too low crawls, and Adam adapts the step for each weight.
  5. More capacity isn't free. Bigger networks take longer to train and can overfit noisy data, so watch the gap between training and test loss.
