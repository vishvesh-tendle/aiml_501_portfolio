# AIML-501 Model Development Portfolio — Vishvesh Tendle

Portfolio of interactive artifacts created for **AIML-501: Model Development** in the M.S. in Artificial Intelligence program at Indiana Wesleyan University.

**Live site:** https://vishvesh-tendle.github.io/aiml-501-portfolio/

## Artifacts

| # | Artifact | Description |
|---|----------|-------------|
| 01 | [The ML Algorithm Atlas](artifacts/ml-algorithm-atlas.html) | Interactive visual framework of 12 ML algorithms classified by learning style and application domain, with live in-browser demos |

## Structure

```
index.html                      ← portfolio home page
artifacts/
  ml-algorithm-atlas.html       ← Artifact 01
```

All pages are self-contained HTML/CSS/JavaScript with no build step, hosted on GitHub Pages.

## Adding a new artifact

1. Put the new page in `artifacts/`.
2. In `index.html`, add an entry to the `ARTIFACTS` list at the top of the script (or replace a "Coming soon" placeholder).
3. Commit — GitHub Pages redeploys automatically.
